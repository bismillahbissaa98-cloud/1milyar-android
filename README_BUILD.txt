1Milyar.com Android project

Basis:
- 1Milyar_com_MultiDevice_v1.html
- Wrapped in Android WebView
- Portrait mobile layout
- JavaScript + localStorage enabled
- Internet permission included for future cloud sync

IMPORTANT:
This package is the Android project source, not a pre-built APK.
To produce an installable APK, open this folder in Android Studio and build:
Build > Build App Bundle(s) / APK(s) > Build APK(s).

Cloud synchronization is NOT claimed active yet. The HTML currently retains local storage behavior.
